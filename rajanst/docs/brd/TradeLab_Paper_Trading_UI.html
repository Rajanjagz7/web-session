TSL test protocol

  1. Freeze the same entry, initial SL and target plan for each method.
  2. Define the activation threshold and trail distance before reviewing outcomes.
  3. Record the stop update sequence and maximum favourable/adverse excursion.
  4. Compare net P&L, R, drawdown, early-exit rate, and T2/T3 capture.
  5. If stop and target are both touched within one candle, label the result ambiguous unless intrabar order is known.
