## DAY 1 — 24 Oct 2026 (feature wave)

### 1. Z Trend (Rajan Zone Trend) — one engine everywhere
- New **`rzt.py`**: server-side Z Trend engine. `GET /api/m/rzt` returns state (BUY/SELL),
  price, the drawn stop line, zone resistance/support, last flip, and a flip-by-flip table
  (entry → exit → points) — the "backtest it live" view.
- Daily-bar runner added to `backtest._runners()` → the auto trader scans Z Trend with every
  other indicator; Z Trend 5-minute flips are also direct auto-trader candidates.
- **Intraday Z Trend as HEDGED CREDIT SPREADS** (`cfg.zTrendHedge`, on by default): sell the
  OTM strike ~1.5 expected moves away on the trend's side, buy the hedge 2 strikes further
  out; exit at 2× credit (SPREAD-STOP) or banking 50% of the credit (SPREAD-T1). The pair is
  managed as ONE position. Accuracy shows in the Algo tab's exit breakdown (SPREAD-* rows).

### 2. Auto trader
- **Day P&L guard** (`dayPnlLimit`, default ±₹30,000): past the limit → no new trades; inside
  the 75% soft zone → only 3-indicator confluence + Z Trend entries. Shown in the Algo status
  card.
- **Option SELL legs only from 09:20** (paired shorts deferred; buys keep the 09:15 window).
- **No re-entry after a stop**: the one-per-symbol-per-day guard now also counts swing trades
  that closed TODAY (this was the re-entry-after-SL bug).
- Scans **every F&O stock (~218)** with every indicator — was 20 curated.

### 3. Journal
- **Trade timestamps**: entry time next to the date, exit time next to the exit type, live
  **Held** column — on every trade table.
- **Trade IDs = just the number** (A43, 9001) with the A/T/M source tag; full ID in tooltips.
- **Algo tab slimmed**: Auto Trader Status (with Day P&L guard row) | Backtest Results (real
  `/api/backtest` data + Reset + filter-based runs + Upcoming-trades preview) | Auto trade
  exits (per-reason counts + filter chips + one pagination). Vedic Gann Report card removed
  (user decision); `/api/v1/*` API family KEPT (user decision).
- **Stock trader**: auto profit lock (₹1,500 breakeven, ₹2,000 trailing 50/60/70%) + L badge;
  pagination on open + closed lists; Rules text block removed (rules still enforced).

### 4. Time cycle & Vedic
- Time Cycle card: **TIME | PRICE | STRENGTH** (price = 5-min close at each cycle), zone
  chips (Vibration / Next resistance / Max pain / Call wall / Put wall), Square-of-9 ladder +
  disclaimer collapsed, table paginated (8/page, opens on the next cycle).
- Vedic Astro page: Time cycle tab removed (lives in Trade → Signals).

### 5. Old-expiry review ("what happened in old expiry")
- **`expiry_book.py`** records every contract key while its chain is live; the Trade screen's

  Expiries appear only after the app fetched their chain at least once (fills from deploy on).

### 6. Trade screen UI
- Signals area: **Order | Signals** tabs on desktop too; inside Signals, Vedic-style sub-tabs:
  **All indicators** (readings + full strategy table merged, with filters + pagination) |

- Mobile: KPI chips wrap, chain re-renders OI | LTP | Strike | LTP | OI, readings wrap.

  but not auto-traded (FIND-2025-08, revisit on request).

### 2. IPO bug (user-reported: closed IPO data not showing)
- **Root cause**: on Vercel, NSE's ipo-current-issue + public-past-issues calls both failed
  (datacenter-IP throttling, failures swallowed) → the rebuild published 0 closed / 0 listed
  and OVERWROTE the last good copy.
- **Fixed**: degenerate-build guard carries the previous copy's listed/closed rows forward
  (flagged stale); a failed build serves the last good copy instead of 500ing; one patient
  NSE retry; listing-performance capped to 24 rows on serverless (30s budget); the tab is
  labelled **"Closed"** (was "Awaiting listing"). `test_ipo_resilience.py` pins it.

### 3. Whole-market Picks for the Stock Trader (user-requested)
- The Picks scan now covers **every listed NSE equity (2,504 non-F&O names)** after the F&O
  218, via a per-day cursor — 120/300 symbols per build.
- **Daily history from NSE's public bhavcopy archive** (`equity_bhav.py`): one ~400KB CSV per
  session covers all equities (archives.nseindia.com, no cookies) — per-symbol Upstox candles
  blew the shared rate budget (149 calls/6.7 min measured). Sessions warm progressively; the
  walk advances ~115 symbols per refresh with ZERO incremental Upstox calls.
- **LIVE data guarantee**: during market hours, today's live bar (from the quote) is appended
  to the bhavcopy history before the indicators run — cash picks are as fresh as F&O ones,
  never last-day bhavcopy data.
- **Strength floor**: cash picks below **55** are dropped (user: 50–60+; one constant,
  `PICK_CASH_MIN_STRENGTH`). Floors also: ≥25k shares traded today, price ≥₹20.
- **Day store accumulates**: the day's cash picks build up across builds
  (`picks:cash|<date>`) — strong names found this morning stay all day.
- **UI**: Market filter row (All markets / F&O / Cash), CASH tag on cards, "Buy (cash)"
  actions, coverage counter (x/2504 today).
- **Horizon bug (user-reported)**: index cards leaked into Intraday/Swing/Positional views —
  any horizon selection now shows stocks only.

### 4. Infra findings
- **Primary Upstash hit its 500,000 request limit** — the app auto-failed over to the backup
  instance (healthy, all keys intact; auto-switches back when the primary recovers). The
  bhavcopy design also keeps the new feature's command footprint small (batched reads: one
  read pass per build via `equity_bhav.load_days()`).
- Serverless refreshes when the market is closed are limited to one per 120s
  (`_allow_refresh`) — space out test refreshes.
- Vercel preview deployments need `vercel curl` (authenticated) — anonymous curl gets a login
  page.
